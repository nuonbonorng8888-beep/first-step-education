📲 របៀបដំឡើង App 1ˢᵗ Step លើទូរស័ព្ទ

1ˢᵗ Step (First Step)

ដំឡើងជា App ពេញលេញលើអេក្រង់ទូរស័ព្ទដៃ ដោយមិនបាច់ចូលតាម Browser រាល់ដង

🤖 Android (Samsung / Oppo...)
  1. បើក Link ក្នុង Google Chrome
  2. ចុចសញ្ញាចុច ៣ (⋮) នៅខាងលើស្ដាំ
  3. ជ្រើសរើស "ដំឡើងកម្មវិធី" (Install app) ឬ "Add to Home screen"
  4. ចុច Install / Add រួចរាល់!
🍏 iPhone / iPad (iOS)
  1. បើក Link ក្នុងកម្មវិធី Safari
  2. ចុចប៊ូតុង Share (⬆️) នៅបាតខាងក្រោម
  3. អូសចុះក្រោម ជ្រើស "Add to Home Screen" (➕)
  4. ចុច Add (បន្ថែម) នៅខាងលើស្ដាំ រួចរាល់!
💡 ចំណាំ៖ បន្ទាប់ពីដំឡើងរួច App នឹងមាន Icon រូបកូនឆ្មា Mascot លើផ្ទាំងទូរស័ព្ទដៃដូច App ផ្លូវការ ហើយបើកបានពេញអេក្រង់ (Full Screen) គ្មានរបារ Browser ឡើយ!
